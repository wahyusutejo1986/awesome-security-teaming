# Taxonomy

**Teams:** `red` (authorized adversary simulation), `blue` (detection/defense/response), `purple` (collaborative validation and learning). Teams are multi-label, not mutually exclusive.

**Capabilities:** see `data/taxonomy.json`. Each tool may have multiple capabilities. Prefer narrowly defined use cases; propose taxonomy changes in the same PR as new categories.

**Verification:** `unverified`, `verified`, `needs-review`. **Maintenance:** `unknown`, `active`, `limited`, `archived`. **Readiness:** `not-assessed`, `experimental`, `lab-ready`, `enterprise-candidate`.

Unknown values are intentional; never fill missing data with assumptions.

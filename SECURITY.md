# Security policy and responsible use

This is a metadata catalog. It does not distribute, execute, or endorse third-party security tooling.

- Only assess assets under explicit authorization and within agreed scope.
- Evaluate offensive tooling in isolated, controlled environments.
- Never upload secrets, credentials, private telemetry, or sensitive incident data in issues or PRs.
- Report vulnerabilities in upstream tools to their respective maintainers, not this catalog.
- For vulnerabilities in this repository's scripts or workflows, use GitHub private vulnerability reporting if enabled, otherwise contact the maintainers privately.
- Treat all repository links as untrusted until verified; do not run remote installation commands without review.
